A [[Regularly Parameterized Curve]]  $\alpha(t)$ can be reparametrized by it's arc length parameter $s$ given by
$$
s(t) = \int_a^t\bigg|\frac{d\alpha}{d\tau}\bigg|d\tau
$$
which is invertible. This means we can write $\alpha$ in terms of $s^{-1}(t)$ so that each point of $\alpha$ corresponds to the length that has been travelled along the curve, $\alpha(s)$.

When this reparameterization is made, $|\dot{\alpha}(s)| = 1$ for all $s$.
